# Stickman AI Comedy Studio

مشروع Android أصلي لإنشاء معاينة قصص Stickman كوميدية وتحريكها محليًا، مع نطق الحوار وتصدير MP4 تجريبي باستخدام MediaCodec.

## الحالة والشفافية
هذه نسخة مصدر أولية متكاملة كبنية تطبيق قابلة للبناء وليست APK موقّعًا أو منتجًا تم اختباره على كل الأجهزة. مولّد القصة الحالي يعمل محليًا بقوالب عربية؛ لا يتطلب مفتاح API. دعم Gemini والأخبار ليس مفعّلًا في هذه النسخة. تصدير MP4 صامت (بدون مسار صوتي) ويعتمد على دعم ترميز H.264 في الهاتف؛ قد تختلف التوافقية حسب الشركة والطراز. افحص الفيديو الناتج قبل النشر.

## البناء
- Android Studio حديث
- JDK 17
- Android SDK 35
- افتح المجلد ثم Sync Gradle ثم Build > Build APK(s).

## تشغيل على الهاتف
يمكن فتح المشروع في بيئة Android تدعم Gradle. لا يحتاج التطبيق إلى Firebase كي يعمل. عند التصدير يحفظ الملف داخل مجلد Movies الخاص بالتطبيق:
`Android/data/com.stickman.comedystudio/files/Movies/`

## ملاحظات مهمة
- معاينة الرسم 2D خفيفة ومصممة لتقليل استهلاك الذاكرة.
- Text-to-Speech يستخدم محرك النظام، وتوفر الصوت العربي يعتمد على أصوات Android المثبتة.
- لا توجد علامات مائية أو اشتراكات.
- لا تضع مفاتيح API أو كلمات مرور داخل GitHub. أضفها لاحقًا عبر إعدادات آمنة.
- المشروع لا يحتوي حاليًا على اتصال Firebase أو Gemini أو مزود أخبار؛ لا تعتبر هذه الخدمات مفعلة بمجرد رفع المستودع.

## هيكل الملفات
- `app/src/main/java/.../MainActivity.kt`: الواجهة والتحكم والصوت.
- `StickmanView.kt`: رسم وتحريك الشخصيات.
- `StoryEngine.kt`: توليد القصة محليًا.
- `VideoExporter.kt`: ترميز MP4 عبر MediaCodec.
